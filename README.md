# 🚀 HowMoney? (얼마니?)

> **"이번달 여러분은 얼마나 벌었을까요?"**

---

## 🎯 1. 기획 배경 및 해결 과제
* **월초 예상급여를 계산하기 위해 ai와 계산기를 사용하는 상황**
* **급여계산기와 알바생들에게 편의성을 제공할 수 있는 사이트 개발하기**

## 👤 2. 타겟 유저 페르소나
* **아르바이트를 하고 있는 누구나**
* **알바 스케줄 관리 개인 스케줄관리 급여 계산 등 모든것을 한번에 처리 할 수 있는 앱이 존재하지 않아 여기저기 돌아다녀야 함**
* **아르바이트생이 필요할 만한 모든 기능을 사이트에 녹이기**

## ⭐ 3. 핵심 기능
> 프론트엔드 환경에서 3주 내에 구현할 수 있는 핵심적인 기능 딱 3가지를 정의합니다.
1. **급여 계산기**: 근무시간, 주간 근무시간, 사업장의 크기등에 따라 바뀌는 시급을 계산하는 기능
2. **스케줄 관리 달력**: 알바 스케줄 관리, 유저의 개인 일정 관리, TOdoList등 여러가지 앱을 사용하던 불편함을 하나로 줄이기
3. **알리미**: 기업, 국가, 사업체에서 진행하는 이벤트 또는 해택을 정리하는 뉴스피드

## 🗺️ 4. 화면 설계 및 유저 플로우
* 사용자가 우리 웹사이트에 접속하여 목표를 달성하기까지의 클릭 흐름을 단계별로 작성합니다.
  1. `메인 페이지` 접속
  2. 메인화면에는 오늘의 급여 그리고 오늘의 스케줄을 표시
  3. 왼쪽으로 스와이프하면 달력기능
  4. 오르쪽으로 스와이프하면 알리미와 급여 계산기 기능표시

## 🛠️ 5. 기술 스택 및 아키텍처

* **스타일링:** Tailwind CSS
